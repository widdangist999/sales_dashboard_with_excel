# Sales Analytics Dashboard | Excel

## Overview
An interactive Sales Dashboard built using Microsoft Excel to analyze sales performance, profitability, and customer segments. The dashboard helps identify sales trends and top-performing products through data visualization.

## Key Metrics
- **Total Sales:** $2,297,201
- **Total Profit:** $286,397
- **Total Quantity:** 37,873
- **Profit Margin:** 12.47%

## Key Insights & Analysis
- Monthly Sales and Profit Margin Trends
- Sales Distribution by Customer Segment
- Top 10 Products Based on Sales
- Regional and Segment Performance

## Dashboard Features
Interactive filters for:
- Year and Month
- Customer Segment
- Region
- State
- Calendar Date

## Tools & Techniques
- Microsoft Excel
- Pivot Tables & Pivot Charts
- Slicers
- Data Analysis
- Data Visualization
